  CAMBIOS: ESCRITURA INMEDIATA EN DISCO DE LOGS
═══════════════════════════════════════════════════════════════════════════════

PROBLEMA ANTERIOR:
─────────────────────────────────────────────────────────────────────────────
Los logs se acumulaban en memoria (StringBuilder) y se escribían todos juntos
al final de la ejecución. Si el programa fallaba o se cerraba inesperadamente,
se perdía toda la información del log.

SOLUCIÓN IMPLEMENTADA:
─────────────────────────────────────────────────────────────────────────────
Ahora cada llamada a EscribirLog() escribe INMEDIATAMENTE en disco usando
File.AppendAllText(), lo que garantiza que:

✅ Cada línea se escribe en disco inmediatamente
✅ Si el programa falla, el log contiene todo hasta ese momento
✅ No se pierde información por cierre inesperado
✅ Múltiples instancias pueden escribir sin conflictos (lock automático)

═══════════════════════════════════════════════════════════════════════════════
  CAMBIOS EN EL CÓDIGO
═══════════════════════════════════════════════════════════════════════════════

1. NUEVA VARIABLE DE CLASE (línea 45)
   ─────────────────────────────────────────────────────────────────────────
   Private LogFilePath As String = ""

   - Almacena la ruta del archivo de log a nivel de clase
   - Accesible desde cualquier método de la clase
   - Se inicializa con los argumentos de línea de comandos

2. ELIMINADA VARIABLE LOCAL logFile
   ─────────────────────────────────────────────────────────────────────────
   - Antes: Dim logFile As String = ""
   - Ahora: Se usa LogFilePath (variable de clase)

3. CREACIÓN DEL DIRECTORIO AL INICIO (líneas 451-468)
   ─────────────────────────────────────────────────────────────────────────
   ' Crear directorio de log si se especificó y no existe
   If Not String.IsNullOrEmpty(LogFilePath) Then
       Try
           Dim logDir As String = IO.Path.GetDirectoryName(LogFilePath)
           If Not String.IsNullOrEmpty(logDir) AndAlso Not IO.Directory.Exists(logDir) Then
               IO.Directory.CreateDirectory(logDir)
           End If
       Catch ex As Exception
           ' Si falla, usar escritorio como fallback
           LogFilePath = IO.Path.Combine(Environment.GetFolderPath(...)
       End Try
   End If

   VENTAJAS:
   - Se verifica y crea el directorio UNA sola vez al inicio
   - Si falla, usa el escritorio automáticamente
   - No se pierden logs por problemas de permisos

4. FUNCIÓN EscribirLog MODIFICADA (líneas 556-603)
   ─────────────────────────────────────────────────────────────────────────
   ANTES:
   ------
   Private Sub EscribirLog(mensaje As String)
       LogSilencioso.AppendLine(mensaje)  ' Solo en memoria
       Debug.Print(mensaje)
   End Sub

   AHORA:
   ------
   Private Sub EscribirLog(mensaje As String)
       ' 1. Añadir al StringBuilder (compatibilidad)
       LogSilencioso.AppendLine(mensaje)

       ' 2. Escribir en Debug (visible con DebugView)
       Debug.Print(mensaje)

       ' 3. Escribir en control Traza si visible
       If Not ModoSilencioso AndAlso Traza IsNot Nothing Then
           Traza.AppendText(mensaje & vbCrLf)
       End If

       ' 4. ✅ ESCRITURA INMEDIATA EN DISCO
       If Not String.IsNullOrEmpty(LogFilePath) Then
           Try
               IO.File.AppendAllText(LogFilePath, mensaje & vbCrLf, Encoding.UTF8)
           Catch ex As Exception
               ' Fallback al escritorio si falla
               ...
           End Try
       End If
   End Sub

   CARACTERÍSTICAS:
   ✓ File.AppendAllText hace lock automático (thread-safe)
   ✓ Escritura atómica (todo o nada)
   ✓ Encoding UTF-8 explícito (soporte para caracteres especiales)
   ✓ Manejo de errores robusto con fallback
   ✓ No interrumpe el programa si falla la escritura

5. ELIMINADO CÓDIGO DE GUARDADO FINAL
   ─────────────────────────────────────────────────────────────────────────
   Se eliminaron ~30 líneas de código que guardaban el log al final,
   ya que ahora cada línea se escribe inmediatamente.

   SIMPLIFICADO DE:
   ----------------
   If Not String.IsNullOrEmpty(logFile) Then
       Try
           Dim logDir As String = IO.Path.GetDirectoryName(logFile)
           IO.Directory.CreateDirectory(logDir)
           IO.File.WriteAllText(logFile, LogSilencioso.ToString(), ...)
           ... (manejo de errores)
       Catch
           ... (fallback al escritorio)
       End Try
   End If

   A:
   --
   EscribirLog($"Log guardado en: {LogFilePath}")
   ' Ya está escrito en disco, solo mensaje informativo

═══════════════════════════════════════════════════════════════════════════════
  FALLBACK AUTOMÁTICO AL ESCRITORIO
═══════════════════════════════════════════════════════════════════════════════

Si hay problemas escribiendo en C:\Logs\actualizar.txt:

1. El programa detecta el error en la primera escritura
2. Cambia automáticamente a: Desktop\API_FS_WOO_Log.txt
3. Todas las escrituras siguientes van al escritorio
4. El log en Debug muestra: [LOG] Cambiado a ruta fallback: ...

CAUSAS COMUNES DE FALLBACK:
- Permisos insuficientes en C:\Logs
- Disco lleno
- Ruta de red no disponible
- Antivirus bloqueando escritura
