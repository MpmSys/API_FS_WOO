  PROBLEMAS COMUNES Y SOLUCIONES
═══════════════════════════════════════════════════════════════════════════════

PROBLEMA: El archivo de log no se crea
───────────────────────────────────────────────────────────────────────────
✓ Verificar permisos en C:\Logs (crear manualmente y dar permisos)
✓ Buscar Desktop\API_FS_WOO_Log.txt (fallback automático)
✓ Ejecutar DebugView para ver mensajes de error
✓ Verificar sintaxis del argumento: /log:"C:\Logs\actualizar.txt"

PROBLEMA: El archivo se crea pero está vacío
───────────────────────────────────────────────────────────────────────────
✓ El programa probablemente se cerró antes de escribir
✓ Ejecutar con DebugView para ver qué pasa
✓ Verificar que no hay errores de conexión a la BD o API
✓ Revisar Desktop\API_FS_WOO_Error.txt por errores

PROBLEMA: La tarea dice "En ejecución" pero no termina
───────────────────────────────────────────────────────────────────────────
✓ Marcar "Detener la tarea si se ejecuta más de: 1 hora"
✓ Verificar conexión a la API de WooCommerce
✓ El log debería mostrar dónde se quedó colgado
✓ Puede estar esperando respuesta de una API que no responde

PROBLEMA: La tarea falla con código de error
───────────────────────────────────────────────────────────────────────────
✓ Revisar pestaña "Historial" de la tarea para ver el código de error
✓ Código 0xFFFFFFFF: Problema con permisos o ruta del ejecutable
✓ Verificar que "Iniciar en" apunta a la carpeta correcta
✓ Verificar que el ejecutable existe en la ruta especificada

PROBLEMA: El log muestra errores de API
───────────────────────────────────────────────────────────────────────────
✓ Verificar credenciales de WooCommerce en la BD
✓ Verificar conectividad a la URL de WooCommerce
✓ El log debería mostrar el error exacto de la API
✓ Verificar que las credenciales no hayan expirado
