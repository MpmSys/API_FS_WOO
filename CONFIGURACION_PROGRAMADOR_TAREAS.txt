  CREAR LA TAREA DESDE XML (MÉTODO ALTERNATIVO)
═══════════════════════════════════════════════════════════════════════════════

1. Guarda el siguiente contenido en un archivo llamado: tarea_actualizar.xml

2. EDITA EL ARCHIVO XML y reemplaza:
   - TUNOMBREDEUSUARIO con tu nombre de usuario de Windows
   - Las rutas del ejecutable con las correctas

3. Importa en Programador de Tareas:
   - Abre Programador de Tareas (taskschd.msc)
   - Clic derecho en "Biblioteca del Programador de tareas"
   - "Importar tarea..."
   - Selecciona el archivo XML
   - Ajusta las credenciales si es necesario

  VERIFICAR QUE LA TAREA FUNCIONE
═══════════════════════════════════════════════════════════════════════════════

1. En Programador de Tareas, busca tu tarea

2. Clic derecho > "Ejecutar"

3. Espera 1-2 minutos

4. Verifica:
   - El archivo C:\Logs\actualizar.txt debe existir
   - El archivo debe tener contenido (no estar vacío)
   - La última línea debe decir "Log guardado en: C:\Logs\actualizar.txt"

5. Si no funciona:
   - Revisa la pestaña "Historial" de la tarea para ver errores
   - Ejecuta el test_actualizar.bat primero (fuera del Programador de Tareas)
   - Usa DebugView (ver DEPURACION_LOGS.txt)

═══════════════════════════════════════════════════════════════════════════════
  PROBLEMAS COMUNES
═══════════════════════════════════════════════════════════════════════════════

PROBLEMA: "El sistema no puede encontrar el archivo especificado"
→ La ruta del ejecutable está mal o no existe
→ Usa la ruta COMPLETA y ABSOLUTA (C:\...)
→ Verifica que el archivo realmente exista en esa ubicación

PROBLEMA: La tarea se ejecuta pero no hace nada
→ Verifica que "Ejecutar con los privilegios más altos" esté marcado
→ Verifica que la carpeta C:\Logs exista (créala manualmente)
→ Verifica permisos de escritura en C:\Logs

PROBLEMA: La tarea aparece como "En ejecución" pero no termina
→ Puede estar colgada esperando una conexión
→ Marca "Detener la tarea si se ejecuta más de: 1 hora"
→ Verifica la conexión a la API de WooCommerce

PROBLEMA: El log se crea pero está vacío
→ El programa probablemente se cerró antes de escribir
→ Verifica que no haya errores en el código
→ Ejecuta manualmente primero: test_actualizar.bat
